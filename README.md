## 📖 About the Project

**THE MAKING OF ABDURRAHMAN** is my personal digital portfolio, designed as an interactive book that tells the story behind my journey in technology, artificial intelligence, software development, education, and personal growth.

Instead of presenting information through a conventional scrolling website, this portfolio transforms my professional journey into an immersive chapter-based experience.

Every chapter represents a different part of my journey — from education and technical skills to projects, achievements, experiences, and future ambitions.

> "Every line of code is part of a bigger story. This is mine."

## ✨ Highlights

- 📚 **Interactive Digital Book** — A chapter-based portfolio with immersive page transitions.
- 🎨 **Cinematic Experience** — A refined visual identity with carefully crafted animations and transitions.
- 🌗 **Dual Theme System** — Elegant light and dark themes.
- 🧑‍💻 **Personal Introduction** — Discover the person behind the code.
- 🎓 **Education Journey** — Explore my academic background and learning path.
- 🛠️ **Technology Arsenal** — An overview of my technical skills and tools.
- 🚀 **Project Showcase** — Explore selected projects and development work.
- 📝 **Digital Journal** — Technical articles, project stories, lessons, and reflections.
- 🤖 **AUREVON AI Integration** — An AI-powered experience connected to my personal AI project.
- 📬 **Contact Experience** — A dedicated space for professional communication.

## 🧰 Technology & Tools

The portfolio's development stack includes technologies such as:

- **Frontend:** React, TypeScript, Vite
- **Styling:** Tailwind CSS
- **Animation:** Framer Motion
- **3D & Interactive Graphics:** Three.js / React Three Fiber
- **Backend & APIs:** Python, FastAPI
- **Database:** Supabase / PostgreSQL
- **AI Integration:** AUREVON AI
